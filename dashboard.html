Integrasi WhatsApp

Hubungkan bot AI ke nomor WhatsApp toko via scan QR atau kode pairing nomor HP

Memeriksa...
Tahapan Menautkan Bot via QR Code
  1. Pastikan server backend SellBot AI sudah berjalan.
  2. Buka aplikasi WhatsApp di HP Anda.
  3. Masuk ke Perangkat Tertaut (Android: Titik Tiga — iOS: Pengaturan).
  4. Tekan Tautkan Perangkat, lalu arahkan kamera ke QR Code di bawah.
  5. Setelah tersambung, bot akan aktif otomatis membalas pesan pelanggan 🎉
Tahapan Menautkan Bot via Nomor HP (Tanpa Kamera)
  1. Masukkan nomor WhatsApp toko Anda pada kolom di bawah (contoh: 081234567890).
  2. Klik tombol "Dapatkan Kode Pairing" untuk menerima 8 digit kode pairing.
  3. Buka aplikasi WhatsApp di HP Anda > Perangkat Tertaut.
  4. Pilih Tautkan Perangkat, lalu ketuk tautan di bawah: "Tautkan dengan nomor telepon saja".
  5. Masukkan 8 digit kode pairing yang tampil di layar. WhatsApp langsung terhubung! 🎉
